# 🎓 Student Performance & Analytics Portal

A modern, interactive web-based analytics dashboard built with **Python**, **Streamlit**, and **Plotly** to track, analyze, and visualize student academic performance, attendance records, and examination metrics.

---

## 🚀 Key Features

* **Real-time KPI Metrics:** Instantly view total students, class averages, pass rates, average attendance, and top scorers.
* **Advanced Chart Visualizations:**
  * **Bar Chart:** Subject-wise class average marks breakdown.
  * **Donut Chart:** Pass vs. Fail ratio distribution.
  * **Scatter Plot:** Correlation analysis between attendance percentages and average scores.
  * **Box Plot:** Score range distribution and outlier detection per subject.
* **Interactive Department & Semester Filters:** Filter data dynamically from the sidebar.
* **Individual Student Deep-Dive:** Select any student from the dropdown to check their comprehensive report card, subject breakdown, and status.
* **CSV Data Upload:** Upload custom dataset CSV files to analyze different classes or batches.
* **Export Report:** Download filtered analytical reports directly as a CSV file.

---

## 🛠️ Tech Stack

* **Programming Language:** Python 3.8+
* **Framework:** Streamlit
* **Data Processing:** Pandas
* **Data Visualization:** Plotly (Express & Graph Objects)
